# Grassdoro v2

A cross-platform Pomodoro desktop app built with Electron + React + Vite + Tailwind CSS.

## Features

- Pomodoro timer with focus/break/long-break cycles
- Floating widget for quick access
- Lock screen during breaks
- Lofi background music
- Prayer time integration
- Session statistics
- Auto-launch on startup
- Do Not Disturb mode

## Platforms

- Windows (.exe)
- macOS (.dmg)
- Linux (.deb)

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm package:win
pnpm package:mac
pnpm package:linux
```
